# Release acceptance

1. Review the scientific matrix, the full benchmark data and documented adverse results.
2. Require the scientific acceptance workflow and compatibility tests on the candidate.
3. Review separate statement and branch coverage, lint, format and type checks.
4. Confirm all distributions pass strict Twine validation and install outside the source tree.
5. Verify all fifteen advanced API symbols and ShotWeave 0.2.0 interoperability.
6. Obtain final project-owner approval before promotion or publication.
7. Record tag commit and successful Trusted Publishing job. Download published GitHub and PyPI files and compare SHA-256 against the same build artifacts.
8. Verify installation from the public index and distinguish skipped publishing from successful publication.

See the [acceptance report](acceptance-report.md) for the evidence reviewed before approval.
